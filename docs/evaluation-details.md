# 文章テストと公開STTの検証結果

[日本人フルネームの評価](../EVALUATION.md)

## 日本人名のマスク例

フルネームの読みを登録し、手作りの20文を既定の長さ別上限で検索した。対象の20か所のうち **全体マスク19、一部マスク1、完全露出0**。対象外では、読みが似た別人「オノユウスケ」も1か所隠れた。表の各行で、敬称・句読点を含む出力全文をテストしている。[文章と期待値](../testdata/transcripts.tsv)

### 読みの違いとマスク範囲

| 確認したこと | 登録したフルネーム | 入力した文章 | マスク結果 |
|---|---|---|---|
| シイ／シーと中黒 | イシーカオリ | 受付でイシイ・カオリさんを呼んだ。 | 受付で■さんを呼んだ。 |
| ユウ／ユー | ヤマモトユウスケ | 司会はヤマモトユースケさんです。 | 司会は■さんです。 |
| セイ／セー | キムラセイスケ | 次はキムラセースケさん。 | 次は■さん。 |
| コウ／コー | ミズノコウスケ | 担当はミズノコースケさん。 | 担当は■さん。 |
| 姓のザ／サ（清濁） | ヤマザキケント | 書類はヤマサキケントさんに渡しました。 | 書類は■さんに渡しました。 |
| キクコ／キッコ（促音化） | サトウキクコ | 受付でサトウ・キッコさんをお呼びしました。 | 受付で■さんをお呼びしました。 |
| シュウ／シウ（拗音） | タナカシュウジ | 折り返しはタナカシウジ様へお願いします。 | 折り返しは■様へお願いします。 |
| サイトウ／サトウ・カトウ | サイトウヒロキ | サトウヒロキさんとカトウヒロキさん。 | ■さんと■さん。 |
| 姓の音が変わり、名は長音符に | サイトウユウスケ | 引き継ぎはカトウユースケさん。 | 引き継ぎは■さん。 |
| 先頭のアが脱落（直前の「で」もマスク） | アサクラタカヒロ | 受付でサクラタカヒロさんを呼んだ。 | 受付■さんを呼んだ。 |
| 姓の途中のクが脱落し、名は長音符に | キクチユウスケ | 記録はキチユースケさんの分です。 | 記録は■さんの分です。 |
| 語尾のリが脱落 | イシーカオリ | イシイカオさんが来た。 | ■さんが来た。 |
| 語尾のタが脱落 | イシダリョウタ | イシダリョウさん。 | ■さん。 |
| 姓の頭にオが増える（一部マスク） | オノアキ | 受付でオオノアキさんを呼びました。 | 受付でオ■さんを呼びました。 |

### 氏名の周囲と対象外の表記

| 確認したこと | 登録したフルネーム | 入力した文章 | マスク結果 |
|---|---|---|---|
| 普通名詞「おさとう」と人名 | サトウミホ | おさとうを加えてください。次はサトーミホさんの番です。 | おさとうを加えてください。次は■さんの番です。 |
| 同じ姓の別人 | イシイカオリ | イシイユウコさんの後にイシーカオリさんが話した。 | イシイユウコさんの後に■さんが話した。 |
| 同じ名の別人 | ミズノユウスケ | ミズノユースケさんとフジタユースケさんが同席した。 | ■さんとフジタユースケさんが同席した。 |
| 姓のみ・名のみの呼びかけ | サトウレーナ | サトウさんとレナさん。あとでサトウレーナさんも来た。 | サトウさんとレナさん。あとで■さんも来た。 |
| 句点で途切れた読み | サトウレナ | サトウ。レナさん。 | サトウ。レナさん。 |
| 別人のフルネームもマスクされた例 | オオノユウスケ | 担当はオオノユウスケさん。同席したのは別人のオノユウスケさん。 | 担当は■さん。同席したのは別人の■さん。 |

一部マスクの「オ■」は先頭のオだけが残った結果。「イシイカオ → ■」のように文字起こしですでに語尾が落ちた場合、本文に現れた氏名がすべて隠れれば全体マスクと数える。

### 評価データの範囲

この20文はかな表記の違いとマスク範囲を再現するための回帰例。実際のSTTでそれぞれの揺れが起きる頻度は未測定。別の促音化テストでも、登録名「サトウキクコ」で `受付は「サトウキッコ」です。` が `受付は「■」です。` になる。[促音化のテスト](../match_test.go)

公開STTの漢字出力から人手で読みを仮定した補助テストも2件ある。この2件は上の20か所にも、公開STTのかなフルネーム集計にも含めていない。[読みの根拠・元の発話](../DATA_SOURCES.md#日本人名の発話別stt出力)

| 登録したフルネーム | 仮定した読み | マスク結果（氏名部分） |
|---|---|---|
| ノグチヒデヨ | ノグチヒデオ | ■オ |
| ヤマザキケント | ヤマザキケンタ | ■タ |

表の20文と補助テストの再現手順

```sh
cases='spelling-(ishi|yuu|ei|ou)|jp-.*|stt-(vowels|tail|ryouta)|both-components|head-loss|length-ono-partial'
controls='shared-(family|given)|component-only|similar-full-name|boundary-punctuation'
go test -count=1 -v -run "^TestTranscriptCorpus$/(${cases}|${controls})$"
go test -count=1 -v -run '^TestJapaneseASRReadingExamples$'
```

## 公開STTのフルネーム

| テストデータと検索設定 | 対象 | 全体マスク | 一部マスク | 完全露出 |
|---|---:|---:|---:|---:|
| FLEURS・既定の長さ別上限 | 21 | 16 | 3 | 2 |
| Kotoba・既定の長さ別上限 | 11 | 11 | 0 | 0 |
| ReazonSpeech small・韓国人名の追加16発話・既定の長さ別上限 | 16 | 11 | 3 | 2 |
| FLEURS・呼び出し側がさらに `1.5` に制限 | 21 | 15 | 3 | 3 |

Kotobaの氏名は全角カタカナに統一した。1件は1発話の1モデル出力。同じ発話でもモデルによって表記が変わる。正解と認識結果で人名の範囲を確認し、その登録読みを1件ずつ渡して、文章内のマスク範囲を照合した。結果は選定した例に対する件数で、GPT Liveでの発生率は未測定。[FLEURSの各出力](../testdata/fleurs_names.tsv)・[Kotobaの各出力](../testdata/kotoba_kana_names.tsv)

### 実際にどこが隠れるか

登録名「トゥプア・タマセーゼ・レアロフィ」、認識結果「トワッパー・タマセ・ゼ・デアロフィ」は FLEURS の `fleurs-0333`（Whisper large-v3-turbo）。この名前には既定の長さ別上限 `2` が適用される。

| 登録時の設定 | 距離 | `Mask` の出力 |
|---|---:|---|
| 標準設定（`AllRules`）、`ForeignRules` のどちらでも | 2 | 記録は「■」です。 |

登録名に「トゥ」「フィ」があるので、パの後の長音挿入とセの後の長音脱落が各 `0.5`。これにトゥ → トワの `0.25`、プア → ッパの `0.25`、レ → デの `0.5` が加わる。

| 登録したフルネーム | 文字起こしの氏名（カタカナ） | 氏名部分のマスク結果 |
|---|---|---|
| リー・シェン・ルーン | ディ・シェン・ルーン | ■（標準設定、距離 `1.25`） |
| リー・シェン・ルーン | ディー・シェン・ルーン | ■（標準設定、距離 `0.5`） |
| トゥプア・タマセーゼ・レアロフィ | トゥプワ・タマセーゼ・レアロフィー | ■ー |
| エルモア・ジェイムズ | エルモハジェームズ | ■ |
| ジョシュ・ホーキンソン | ジョジホーキンソン | ■ |
| ジェームズ・バリ | ジェームス・パル | ■ |
| キム・シウ | キム・シュウ | ■ |

FLEURSの一部マスク3件は、どちらの設定でも「トゥプア・タマセーゼ・レアロフィ」の別出力。いずれも氏名末尾の長音符だけが残り、出力は `記録は「■ー」です。` になる。[3件のモデル・発話ID・観測表記](../testdata/fleurs_names.tsv)

## 韓国人名のマスク例

日本語の放送をWhisper large-v3が文字起こしした **16人・18発話** を検証した。内訳は上のKotobaのうち2発話とReazonSpeech smallの16発話。正解文の読みを1件ずつ登録し、実際の出力にある氏名を `記録は「氏名」です。` に入れた。既定の長さ別上限で **全体マスク13件、一部マスク3件、完全露出2件**。中黒以外のかなが変わったのは9件、中黒だけが変わったのは4件、表記が同じ対照例は5件だった。

| `000/621d207bed43c.flac` | ハン・ハクチャ | ハン・ハクチャー | 0.75 | ■ー |

## 名前の一部が欠けた場合

登録する読みは「トゥプア・タマセーゼ・レアロフィ」のまま、本文の氏名だけを短くして作った回帰テスト。既定の長さ別上限を使い、トゥ → トワとプア → ッパの割引を無効にしても、既存の脱落規則で次の結果になる。

| 本文に現れた名前 | 欠けた音 | 距離 | 置換後の文章 |
|---|---|---:|---|
| トゥプア・タマセゼ・レアロ | 長音「ー」と語尾「フィ」 | 1.25 | 先ほど、［氏名］さんが受付に来ました。 |
| トゥプア・タマセーゼ・レアフィ | 語中の「ロ」 | 1 | 先ほど、［氏名］さんが受付に来ました。 |

## 文章の回帰テスト

典拠の異表記や手作りの聞き違いを含む65文に、姓と名をつないだ読みを渡した。既定の長さ別上限で必須対象70か所のうち66か所が全体マスク、4か所が一部マスク、完全露出は0か所。許容した類似の別人名の検出は2件、その他の対象外の検出は12件。上の公開STT出力と手作りの短縮例は、この70か所には含めない。

| 登録したフルネーム | 本文 | 現行の既定値 |
|---|---|---|
| ウィリアムウィリス | 記録にはウイリアム・ウイリスとある。 | 記録には■とある。 |
| ハーバートジョージウェルズ | 資料にはハーバート・ジョージ・ウエルズとある。 | 資料には■とある。 |
| セオドアトマス | 資料の著者はセオドアトーマス。 | 資料の著者は■。 |
| セオドアトーマス | 指揮はスイオドア・トマス。 | 指揮はス■。 |
| ウィリアムシェイクスピア | 目録にはウィリアム・シエクスピヤとある。 | 目録には■ヤとある。 |
| オノアキ | 受付でオオノアキさんを呼びました。 | 受付でオ■さんを呼びました。 |
| イシーカオリ | イシイカオさんが来た。 | ■さんが来た。 |
| オオノユウスケ | 担当はオオノユウスケさん。同席したのは別人のオノユウスケさん。 | 担当は■さん。同席したのは別人の■さん。 |
| アサクラタカヒロ | 担当はアサクラタカヒロさん。別人のササクラタカヒロさんも来た。 | 担当は■さん。別人の■さんも来た。 |

ほかに「サトウキクコ → サトウキッコ」は既定の `KuGemination` で距離 `0.5` となり、氏名全体を隠す。

## 先頭部分の任意マスク

登録読みは「サトウマサヒロ」1件。`MatchPrefixes` を有効にした列では3文字・4文字・5文字の先頭一致を、順に距離 `0.75 / 1.0 / 1.25` 以下で拾う。上のフルネーム評価はすべてこの設定を無効にして集計した。

| 本文 | 既定のマスク | 先頭部分もマスク |
|---|---|---|
| サト、サトウ、サトーマザ、サトウマサヒロ、マサヒロ。 | サト、サトウ、サトーマザ、■、マサヒロ。 | サト、■、■、■、マサヒロ。 |
| おさとうを加えてください。サトウユウコさんも来ます。 | おさとうを加えてください。サトウユウコさんも来ます。 | お■加えてください。■ウコさんも来ます。 |

「サトーマザ」は姓を越えて登録読みの先頭5文字に対応し、距離は `0.25`。2行目では普通名詞と同姓の別人もマスクされる。[再現テスト](../prefix_test.go)

## 再現方法

| テストファイル | 何を確認するか |
|---|---|
| [corpus_test.go](../corpus_test.go) | TSVの登録読みで本文を検索し、置換後の文章を期待値と照合する。日本人名の規則別集計は `TestJapaneseFullNameMasks`。韓国人名のWhisper出力は `TestKotobaKanaNameMasks` と `TestKoreanASRNameMasks`、日本人名を含む手作りの文章は `TestTranscriptCorpus` で検証する。 |
| [foreign_spelling_test.go](../foreign_spelling_test.go) | トゥ → トワ、プア → ッパ、別読みごとの長音コストを個別に検証する。トゥプアのフルネームでは距離、閾値の境界、原文のマスク範囲を確認する。 |
| [match_test.go](../match_test.go) | 日本人名の促音化を含む照合規則、長さ別上限の境界と変更、検索・置換の公開APIを検証する。 |

`testdata/transcripts.tsv` の `【名前】` は必須の範囲、`【?名前】` は似た別人名としてマスクしてもよい範囲。FLEURS・Kotoba のTSVでは、期待マスク `=` が完全露出を表す。テストは敬称や句読点を含む置換後の文章も確認する。

```sh
go test -count=1 -v -run 'TestFLEURSNameMasks|TestKotobaKanaNameMasks|TestKoreanASRNameMasks|TestTranscriptCorpus|TestShortenedTupuaTranscript|TestTupuaFullNameMask|TestKuGeminationMask'
```
