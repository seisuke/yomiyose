# 照合規則と重み

`DefaultWeights()` が返す重みを変更してから、名前の読みと一緒に `NewReadings` に渡します。たとえば語尾の脱落を拾いやすくするには、`TailLoss` を既定値の `0.75` から下げます。

```go
w := yomiyose.DefaultWeights()
w.TailLoss = 0.5
m, err := yomiyose.NewReadings([]string{"イシイカオリ"}, w)
```

## 重みの一覧

コストが小さいほど読みが近く、複数の違いがある場合は合計コストが最小の経路を採用します。`Find` と `Mask` は閾値と等しい候補も含めます。

表は開発版の既定値です。v0.1.0 では通常の編集は `2`、長音の挿入は `2`、脱落は `1.25`、同じ母音が続く場合の加点は `2`、`GlideAfterOU` は `+Inf` です。`HaAsWa`、`ShiShu`、`RiRu` は v0.1.0 の後に追加しました。

| Weights の項目 | 初期値 | 適用範囲 | 用途 |
|---|---:|---|---|
| LongSpelling | 0 | 共通 | ユウ／ユー、シイ／シーなど、同母音の反復と長音符 |
| EiSpelling | 0 | 共通 | セイ／セー、デイ／デー |
| OuSpelling | 0 | 共通 | トウ／トー |
| LongLoss | 0.25 | 音の並びで区分 | 日本人名はオオノ／オノ、外国人名はデビット／デービットなどの長音の増減 |
| FinalLongLoss | 0.125 | 外国人名 | エディー／エディなど、採用した語末の長音の増減 |
| LongInsertion | 0.75 | 全規則・日本人名 | 登録読みの短い母音が本文で伸びた場合 |
| LongDeletion | 0.75 | 全規則・日本人名 | 登録読みの長音が本文で短くなった場合 |
| ForeignLongInsertion | 0.5 | 外国人名を明示 | 通常の長音挿入。登録名に `ForeignRules` を指定したときの重み |
| ForeignLongDeletion | 0.5 | 外国人名を明示 | 通常の長音脱落。同じ指定のときに使う |
| RepeatedVowelPenalty | 0 | 日本人名 | 子音で始まり母音がそろう3モーラ以上の並びで、母音の長さが変わった場合の加点 |
| VowelLoss | 0.25 | 日本人名 | サイトウ／サトウのような、ai の i の有無 |
| KuGemination | 0.5 | 日本人名 | 語中のクが、同じカ行音の直前でッとして観測される（キクコ → キッコ）。v0.1.0 の後に追加 |
| GlideAfterOU | 0.25 | 外国人名 | 前後が同じ読みで、直前のモーラの母音がオまたはウのときのア／ワ |
| HaAsWa | 0.125 | 共通 | 同じ前後条件で、登録読みのワに対して本文がひらがなの「は」の場合。登録がアなら、外国人名向けの GlideAfterOU と合算する |
| Geminate | 0.25 | 外国人名 | デビット／デビト、ミッシェル／ミシェルなど、条件付きの促音の有無 |
| BV | 0.25 | 外国人名 | ビ／ヴィを含む、同じ母音を持つバ行とヴの対応 |
| TiChi | 0.25 | 外国人名 | マーティン／マーチンのようなティ／チの交替 |
| TuToWa | 0.25 | 外国人名 | 登録読みのトゥが本文でトまたはトワになる |
| PuaContraction | 0.25 | 外国人名 | 登録読みのプアが本文でパまたはッパになる。ッも同じ編集に含む |
| KanaSize | 0.25 | 外国人名 | ウィ／ウイ、ウェ／ウエ、シェ／シエを双方向に照合。1組あたりの重み |
| ShiShu | 0.5 | 共通 | シ／シュの交替。タナカシュウジ／タナカシウジ、キム・シウ／キム・シュウはともに0.5 |
| RiRu | 0.5 | 外国人名 | リ／ルの交替。ジェームズ・バリ／ジェームス・パルはズ／ス、バ／パと合わせて1.0 |
| RD | 0.5 | 外国人名 | ラ／ダ、リ／ディ、レ／デ、ロ／ドを双方向に照合。通常は直前と直後、登録読みの先頭・末尾では内側の2モーラが本文と一致する場合。語頭のリ／ディでは直後の長音符が落ちても、その先の2モーラが一致すれば適用。脱落のコストは別に加算。v0.1.0 の後に追加 |
| MedialVoicing | 0.25 | 共通、ジェ／シェ・バ／パは外国人名向け | フルネームの先頭以外で清音・濁音が替わる場合。ジェームズ・パジェット／ジェームス・パシェットはズ／スとジェ／シェの2か所で合計0.5 |
| InitialKS | 0.5 | 日本人名 | 語頭のカ行／サ行で母音が対応するもの（カトウ／サトウ） |
| MedialLoss | 1 | 共通 | 登録読みの途中で1モーラが欠ける（タナカユウスケ → タカユウスケ）。逆向きの挿入は通常 `1`。v0.1.0 の後に追加 |
| TailLoss | 0.75 | 共通 | 登録名の最後の母音を含む1モーラが本文で欠ける（リョウタ → リョウ） |
| HeadLoss | 1 | 共通 | 本文検索で、登録名の先頭1モーラを省いた長い区間を部分マスクする |
| Other | 1 | 共通 | その他の読みの1モーラの挿入・脱落・置換 |
| Hiragana | 0.125 | 共通 | 本文で元がひらがなだった1モーラごとの加点。0にするとカタカナと同点 |

たとえば `m.Distance("サイトウ", "カトウ")` は、語頭の置換 `0.5` とイの脱落 `0.25` を合わせて `0.75` です。`Distance(登録読み, 観測した読み)` は読み全体を比較します。本文検索では、元がひらがなのモーラごとに `Hiragana` を加えるため、「イシイカオリ」は `0`、「いしいかおり」は `0.75` で一致します。

編集コストを `math.Inf(1)`（正の無限大）にすると、その操作を含む経路は有限の閾値を超えます。他の規則で同じ差を説明できれば、その経路で一致します。

## 長音・促音と仮名の揺れ

長音符は内部で `:`、促音は `^` として扱います。「レイナ／レーナ」は長さが同じなので距離は `0` です。読みだけを登録すると「レーナ／レナ」のような一般の長音の増減はどちら向きも `0.75` です。「サトウレーナ → サトレナ」のように別の位置で長音が2つ落ちると、合計は `1.5` になります。

- `LongLoss` は、日本人名向けではオ＋ノの間に適用します。外国人名向けではデ＋ビ／ヴィ、シェ＋ク、ニ＋ナ、ヨ＋ハ、ル＋チの間、マリの直後、ト＋マスの間に適用します。登録読みの末尾がディ、ティ、マリの場合には `FinalLongLoss` も適用できます。
- 「タナカミホ → ターナカミホ」は既定値で `0.75` です。子音で始まり同じ母音で終わるモーラが3つ以上続く位置で、一般の長音変化を高くしたい場合は `RepeatedVowelPenalty` に加点分を指定します。
- `KuGemination` は、登録したクの直前が母音で終わるモーラで、直後が k で始まるモーラのときに使います。前後のモーラが本文でも一致すると、「サトウキクコ → サトウキッコ」は `0.5` です。逆向きは通常の置換で `1` です。
- 促音の増減に `Geminate` を使う条件は、直前の母音が i または u で、前後のモーラが対応し、後続子音が k・s・t・p・ch・f・h 系の場合です。「エムバペ／エムバッペ」のバとペの間にも適用します。ト／ドやビ／ヴィも同時に替わる場合はその置換分を加算します。「タナカ／タナッカ」は通常コストの `1` です。
- 「ウィリアムウィリス → ウイリアム・ウイリス」は大小の仮名の違いが2か所あり、距離は `0.5` です。「ジョシュ・ホーキンソン → ジョジホーキンソン」のシュ／ジには `ShiShu + MedialVoicing` を適用し、距離は `0.75` です。
- 「エルドアン／エルドワン」は前後のドとンが一致し、ドの母音がオなので `GlideAfterOU` を適用できます。「エルモア・ジェイムズ → エルモはジェームズ」は `GlideAfterOU + HaAsWa` で距離 `0.375`、本文検索ではひらがな1モーラを加えて `0.5` です。

## 登録名ごとの規則

同じ人の既知の別読みを登録する場合は、`Name.Text` に代表表記、`Name.Readings` に別読みを設定して `New` に渡します。

`New` と `NewReadings` は全規則を使います。日本人名の例から設計した規則と、外国人名の日本語表記から設計した規則を使い分けたいときは、`NewScoped` に姓と名をつないだ読みと規則を渡します。日本人名・外国人名の自動判定は行わず、区分は呼び出し側が選びます。通常の長音コスト `ForeignLongInsertion` と `ForeignLongDeletion` は `ForeignRules` を明示したときだけ使います。名前の由来が不明な場合や、姓と名で両方の規則を使いたい場合は `AllRules`（未指定時の値）を選べます。

```go
m, err := yomiyose.NewScoped([]yomiyose.ScopedName{
	{Name: yomiyose.Name{Text: "サイトウミホ"}, Rules: yomiyose.JapaneseRules},
	{Name: yomiyose.Name{Text: "デビットマッキー"}, Rules: yomiyose.ForeignRules},
}, yomiyose.DefaultWeights())
if err != nil {
	return err
}
text := "受付にサトウミホさん、デービット・マッキーさんがいます。"
fmt.Println(m.Mask(text, 0.25, "■")) // 受付に■さん、■さんがいます。
```

指定した規則はその登録名の別読みにも適用します。読み2件だけを比較するときは `m.DistanceWithRules(登録読み, 観測した読み, 規則)` で同じ区分を指定できます。`m.Distance` は全規則で計算します。

## 名前の長さと検索閾値

`Find` と `Mask` は、すべての規則区分で登録読みと本文の候補の短いほうのモーラ数を使って上限を選びます。姓と名は連結したまま扱います。中黒・空白・アポストロフィは長さに含めません。拗音の「リョ」は1モーラ、長音を含む「リョウ」は2モーラです。

| 短いほうの長さ | 既定の検索条件 |
|---|---|
| 1モーラ | 正規化した読み全体が一致し、ひらがな加点を含むコストが指定閾値以下。`w.ExactSingleMora = false` で通常の距離も許容 |
| 2モーラ | 指定閾値と `w.TwoMoraMaxCost`（初期値 `1.0`）の小さいほう以下。`math.Inf(1)` で指定閾値のみを使用 |
| 3モーラ以上 | 指定閾値以下 |

開発版では `w.LimitByMoraCount = true` を指定すると、上の条件に加えて6モーラ以下は `1.5`、7〜9モーラは `1.75`、10モーラ以上は `2` を上限とします。3段階すべてを使う呼び出しは `m.Mask(text, 2, "■")` です。呼び出し側が指定した閾値のほうが低ければ、その値を優先します。

指定閾値 `1.5` で「サトウレーナ → サトウレナ」は距離 `0.75` でマスクします。「レーナ」だけを登録すると「レナ」も一致し、一般語「それなら」の「れな」も長音脱落 `0.75` とひらがな2モーラ分の `0.25` で「そ■ら」になります。「サトウレーナ」を登録した場合は「それなら」はそのままです。

## 範囲とマスク

フルネームの完全な露出を防ぐため、`Find` と `Mask` は登録読みの先頭1モーラが欠けた長い区間も候補にします。先頭と次のモーラに母音があり、2番目のモーラが本文の開始音と一致し、そこから登録読みに独立した母音を持つモーラが6個以上ある場合が対象です。長音を表す母音、長音符、促音、撥音はこの6個に数えません。登録名「セオドアトーマス」で「スイオドア・トマス」を検索すると、既定値では先頭のセ → イが通常の置換 `1`、長音脱落が `0.25` で「ス■」になります。`Other = 2`、`HeadLoss = 1.25` とした場合は先頭脱落と長音脱落の合計が `1.5` となり、「スイ■」を返します。読み全体を比較する `Distance` にはこの検索用の割引を適用しません。

- `Find` は原文の順に `Match` を返します。`Start` はUTF-8の開始バイト位置、`End` は終了バイト位置の直後です。`NameIndex` から元の名簿のレコードを取得できます。
- ひらがな・半角カナ・分離した濁点を比較用にそろえ、拗音や「ヴィ」などの組を1モーラと数えます。中黒の「・」「･」は照合から除き、名前の内側にあればマスク範囲に含めます。空白入りの名前は空白を含む表記を登録できます。句読点・改行をまたいで照合しません。
- ローマ字読みには `yuusuke`、`yu:suke`、`yu-suke`、`isii`、`ishii`、`debi^to`、`debitto` などを使えます。原綴りから各国語の発音を自動推定する機能はありません。
- 同じ開始位置・登録読みでは最小コストの区間を選び、同点なら長い方を残します。同じ名前で重なる候補は低コストを優先します。同点で一方が他方を含む場合は長い方を、互いにはみ出す場合は両方を返します。別の登録名の候補は独立に返します。`Mask` は全候補の重なる区間をまとめて置換します。
- 語尾が欠けた候補でも、その直後の長音・促音を挟んで同じ末尾モーラが見えている場合は、その挿入のコストで評価します。「タナッカ」の「タナ」だけを語尾脱落として安く拾うことを防ぎます。
- 短い名前では閾値内に一般語も入り得ます。利用するSTTの文章に対して、マスク漏れと余分に隠した箇所の両方を確認しながら重みを調整してください。

名簿は一度用意すれば、複数の文章・goroutine から共有できます。本文をモーラに分けて出現位置を索引化し、閾値が `Other` より小さいときは語頭で許容する編集を考慮して開始位置を選びます。部分文字列をすべて生成せず、全経路が閾値または発見済みの最良コストを超えたところで比較を終えます。
