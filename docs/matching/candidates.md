# 未採用の規則候補

| 候補 | 採用を見送った理由 |
|---|---|
| 音響距離の近い仮名の一括置換 | kanasimで同母音かつ距離の近い564組を許すと、「イシダリョウタ」を探したときに「イシダリョウさん」の「さ」まで隠れる。割引はフルネームで確認できた音の組ごとに検討する。 |
| ク → プ（直後がッ） | 「グレン・クッシング → グレン・プッシング」は通常の置換で隠せる。この割引を必要とする別の発話は見つからなかった。 |
| ラ行とタ行の一律置換 | 一般語の例はあったが、調べた範囲では、カナ表記のフルネームでラ行とタ行だけが入れ替わった例は見つからなかった。 |
| トゥとトワ、プアとパを無条件に同一視する | 同じ録音でのモデル別の出力が主な根拠。登録読みの「トゥ」が本文で「トワ」に、「プア」が「パ」に変わる向きには割引を適用する。逆方向や他の「ゥ」にまで広げる根拠は乏しい。 |

名前を日本人名・外国人名に自動分類する仕組みは未実装。標準設定では両方の規則を使い、通常の長音の重みだけを登録名の音に応じて選ぶ。[実装済みの照合規則](README.md)・[調査したデータと文献](../../DATA_SOURCES.md)
