# 未採用の規則候補

| 候補 | 採用を見送った理由 |
|---|---|
| 音響距離の近い仮名の一括置換 | kanasimで同母音かつ距離の近い564組を許すと、「イシダリョウタ」が「イシダリョウさん」の敬称「さ」まで拾う。個別のフルネームで再現できる対応から選ぶ。 |
| ク → プ（直後がッ） | 「グレン・クッシング → グレン・プッシング」は既存の通常編集で隠せる。追加規則が必要な別の発話が見つかっていない。 |
| ラ行とタ行の一律置換 | 一般語の例はあったが、この差だけで説明できるかなのフルネームを調査対象から確認できなかった。 |
| トゥとトワ、プアとパを無条件に同一視する | 同じ録音でのモデル別の出力が主な根拠。採用したのは観測方向に重みを持つ規則で、逆方向や他の「ゥ」にも広げる根拠は乏しい。 |

名前を日本人名・外国人名に自動分類する仕組みは未実装。標準設定では両方の規則を使い、通常の長音の重みだけを登録名の音に応じて選ぶ。[実装済みの照合規則](README.md)・[調査したデータと文献](../../DATA_SOURCES.md)
