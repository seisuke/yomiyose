# yomiyose

yomiyose は、日本語の音声認識（STT）で書き起こした文章から、指定したフルネームを探してマスクする Go ライブラリです。「ユウ／ユー」のような長音の表記揺れや、文字起こしで名前の一部が抜けた場合にも対応します。

[日本人フルネームのマスク結果を見る（表記揺れ107例）](EVALUATION.md#フルネームの評価結果)

## インストール

Go 1.22 以降で使えます。

```sh
go get github.com/seisuke/yomiyose@v0.2.0
```

## 使用例

「イシーカオリ」と「ジェームズ・スミス」を探し、一致した箇所を「［氏名］」に置き換えます。出力には、本文中の表記と距離も表示します。

```go
package main

import (
	"fmt"
	"log"

	"github.com/seisuke/yomiyose"
)

func main() {
	m, err := yomiyose.NewReadings([]string{"イシーカオリ", "ジェームズ・スミス"}, yomiyose.DefaultWeights())
	if err != nil {
		log.Fatal(err)
	}
	text := "受付のイシイ・カオリさんと、イシイカオさんが来ました。次はジェイムズ・スミスさんです。"
	for _, h := range m.Find(text, 1.5) {
		fmt.Printf("%s %q %.2f\n", h.Name, text[h.Start:h.End], h.Cost)
	}
	fmt.Println(m.Mask(text, 1.5, "［氏名］"))
}
```

出力

```text
イシーカオリ "イシイ・カオリ" 0.00
イシーカオリ "イシイカオ" 0.75
ジェームズ・スミス "ジェイムズ・スミス" 0.00
受付の［氏名］さんと、［氏名］さんが来ました。次は［氏名］さんです。
```

## 検索とマスク

マスクしたい名前が文字起こしのどこに現れるかを、表記揺れも含めて探します。`Find` は一致した範囲と距離を返し、`Mask` は一致箇所を指定した文字列に置き換えます。

| 検索設定 | 照合する範囲 | マスクしたい名前 | 本文で一致する例 |
|---|---|---|---|
| 既定 | フルネーム | イシーカオリ | イシイ・カオリ、イシイカオ |
| `MatchPrefixes = true` | フルネームとその先頭部分 | サトウマサヒロ | 「サトウから電話です」の「サトウ」 |
| `MatchSubstrings = true` | フルネームと、先頭・途中・末尾の連続した読み | ヤマダタロウ | 「山田タローさん」の「タロー」 |

部分一致の距離上限は、かな3文字で `0.75`、4文字で `1.0`、5文字で `1.25` です。[先頭一致の設定](docs/matching/README.md#登録名の先頭だけを探す)・[途中や末尾の検索](docs/matching/README.md#登録読みの途中や末尾も探す)・[日本人名での比較結果](EVALUATION.md#カナの部分一致)

## 照合の重み

距離は、指定した名前の読みを本文の読みに変えるのに必要な最小の合計コストです。`NewReadings` は日本人名向け・外国人名向けの両方の規則を使います。名前の読みから日本人名・外国人名を自動判定する機能はありません。

| 適用範囲 | `Weights` の項目（抜粋） | 適用する操作 | 既定コスト |
|---|---|---|---:|
| 共通 | `LongSpelling` | 同じ母音の反復と長音符を読み替える（シー ↔ シイ） | 0 |
| 共通 | `EiSpelling` | エ段の長音と「イ」を読み替える（ジェー ↔ ジェイ） | 0 |
| 共通 | `MedialLoss` | 名前の途中で1モーラが欠ける（タナカユウスケ → タカユウスケ） | 1 |
| 共通 | `TailLoss` | 名前の末尾で母音を含む1モーラが欠ける（カオリ → カオ） | 0.75 |
| 共通 | `Other` | 通常の1モーラの挿入・脱落・置換 | 1 |
| 日本人名向け | `VowelLoss` | 母音が a のモーラに続くイの有無（サイトウ ↔ サトウ） | 0.25 |
| 日本人名向け | `KuGemination` | カ行音の前で「ク」が「ッ」になる（キクコ → キッコ） | 0.5 |
| 日本人名向け | `InitialConfusion` | 先頭の K/S、H/K、N/H、M/H（ハマダ ↔ カマダ） | 0.25 |
| 日本人名向け | `InitialConsonant` | 同じ母音・同じ直音／拗音での先頭子音の違い。子音の有無も含む（カ ↔ ア） | 0.5 |
| 外国人名向け | `BV` | 同じ母音をもつバ行とヴの音を置き換える（ビ ↔ ヴィ） | 0.25 |
| 外国人名向け | `Geminate` | 前後の音に応じた促音「ッ」の有無（デビット ↔ デビト） | 0.25 |
| 外国人名向け | `RD` | 近くの2モーラが一致するラ行とダ行の置換（ジャンカルロ ↔ ジャンカルド） | 0.5 |

使用例の「イシーカオリ → イシイカオ」では、「シー → シイ」が `0`、末尾の「リ」の脱落が `0.75` です。合計 `0.75` は指定した閾値 `1.5` 以下なのでマスクされます。

`m.MaskDefault(text, "［氏名］")` と `m.FindDefault(text)` は、指定した名前の読みと本文の候補のうち、短いほうのモーラ数で距離の上限を選びます。1モーラは原則完全一致、2モーラは `1`、3〜6モーラは `1.5`、7〜9モーラは `1.75`、10モーラ以上は `2` です。重みと上限は `DefaultWeights()` の戻り値で調整できます。[重みの一覧と長さ別上限の設定例](docs/matching/README.md#名前の長さと検索閾値)
