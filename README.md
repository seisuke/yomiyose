# yomiyose

日本語の音声認識（STT）の文字起こしから、あらかじめ読みを登録したフルネームを探してマスクする Go ライブラリです。長音の表記揺れや、聞き取りで名前の一部が欠けた場合も照合できます。

[日本人フルネームのマスク結果を見る（表記揺れ107例）](EVALUATION.md#フルネームの評価結果)

## インストール

Go 1.22 以降で使えます。

```sh
go get github.com/seisuke/yomiyose@v0.1.2
```

## 使用例

2人の読みを登録し、語尾が欠けた「イシイカオ」や、「ジェームズ」が「ジェイムズ」と書かれた箇所を探します。`Find` で登録名・本文中の表記・距離を表示し、`Mask` で一致箇所を置き換えます。

```go
package main

import (
	"fmt"
	"log"

	"github.com/seisuke/yomiyose"
)

func main() {
	m, err := yomiyose.NewReadings([]string{"イシーカオリ", "ジェームズ・スミス"}, yomiyose.DefaultWeights())
	if err != nil {
		log.Fatal(err)
	}
	text := "受付のイシイ・カオリさんと、イシイカオさんが来ました。次はジェイムズ・スミスさんです。"
	for _, h := range m.Find(text, 1.5) {
		fmt.Printf("%s %q %.2f\n", h.Name, text[h.Start:h.End], h.Cost)
	}
	fmt.Println(m.Mask(text, 1.5, "［氏名］"))
}
```

出力

```text
イシーカオリ "イシイ・カオリ" 0.00
イシーカオリ "イシイカオ" 0.75
ジェームズ・スミス "ジェイムズ・スミス" 0.00
受付の［氏名］さんと、［氏名］さんが来ました。次は［氏名］さんです。
```

姓と名をつないだ読みを、カタカナ・ひらがな・ローマ字で登録できます。本文中の位置が必要な場合は `Find` を使い、各一致を `text[h.Start:h.End]` で取り出せます。

`DefaultWeights()` の `MatchPrefixes` を `true` にすると、登録名の先頭だけが発話された箇所も拾えます。「サトウマサヒロ」を1件登録すれば「サトウから電話です。」は「■から電話です。」になります。部分一致はかな3〜5文字が対象で、距離の上限は順に `0.75 / 1.0 / 1.25` です。[先頭一致の設定と例](docs/matching/README.md#登録名の先頭だけを探す)

`w.MatchSubstrings = true` にすると、同じ長さ・距離条件で登録読みの途中と末尾も拾えます。「ヤマダタロウ」を登録して「山田タローさん」を検索すると、`FindDefault` が返す範囲は「タロー」です。[部分一致の使い方](docs/matching/README.md#登録読みの途中や末尾も探す)・[日本人名での比較結果](EVALUATION.md#カナの部分一致)

## 照合の重み

読みの違いを説明できる操作のうち、合計コストが最小の組み合わせで距離が決まります。`NewReadings` は日本人名向け・外国人名向けの両方の規則を使います。名前の読みから日本人名・外国人名を自動判定する機能はありません。

| 適用範囲 | `Weights` の項目（抜粋） | 適用する操作 | 既定コスト |
|---|---|---|---:|
| 共通 | `LongSpelling` | 同じ母音の反復と長音符を読み替える（シー ↔ シイ） | 0 |
| 共通 | `EiSpelling` | エ段の長音と「イ」を読み替える（ジェー ↔ ジェイ） | 0 |
| 共通 | `MedialLoss` | 登録名の途中で1モーラが欠ける（タナカユウスケ → タカユウスケ） | 1 |
| 共通 | `TailLoss` | 登録名の末尾で母音を含む1モーラが欠ける（カオリ → カオ） | 0.75 |
| 共通 | `Other` | 通常の1モーラの挿入・脱落・置換 | 1 |
| 日本人名向け | `VowelLoss` | 母音が a のモーラに続くイの有無（サイトウ ↔ サトウ） | 0.25 |
| 日本人名向け | `KuGemination` | カ行音の前で「ク」が「ッ」になる（キクコ → キッコ） | 0.5 |
| 日本人名向け | `InitialConfusion` | 先頭の K/S、H/K、N/H、M/H（ハマダ ↔ カマダ） | 0.25 |
| 日本人名向け | `InitialConsonant` | 同じ母音・同じ直音／拗音での先頭子音の違い。子音の有無も含む（カ ↔ ア） | 0.5 |
| 外国人名向け | `BV` | 同じ母音をもつバ行とヴの音を置き換える（ビ ↔ ヴィ） | 0.25 |
| 外国人名向け | `Geminate` | 前後の音に応じた促音「ッ」の有無（デビット ↔ デビト） | 0.25 |
| 外国人名向け | `RD` | 近くの2モーラが一致するラ行とダ行の置換（ジャンカルロ ↔ ジャンカルド） | 0.5 |

トゥ → ト／トワ、プア → パ／ッパをそれぞれ1回の編集（各 `0.25`）として扱います。通常の長音の挿入・脱落は `0.75` ですが、登録名に「トゥ」「ヴィ」「フィ」などの音があれば、標準設定で `0.5` を使います。

使用例の「イシーカオリ → イシイカオ」では、「シー → シイ」が `0`、末尾の「リ」の脱落が `0.75` です。合計 `0.75` は指定した閾値 `1.5` 以下なのでマスクされます。

`m.MaskDefault(text, "［氏名］")` と `m.FindDefault(text)` が名前の長さに応じて上限を選びます。1モーラは原則完全一致、2モーラは `1`、3〜6モーラは `1.5`、7〜9モーラは `1.75`、10モーラ以上は `2` です。照合の重みと各上限は `DefaultWeights()` で得た設定から変更できます。[重みの一覧と長さ別上限の設定例](docs/matching/README.md#名前の長さと検索閾値)
