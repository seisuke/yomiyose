# yomiyose

yomiyose は、日本語の音声認識（STT）の文字起こしから、あらかじめ読みを登録した人名を探してマスクする Go ライブラリです。長音・促音の表記揺れや聞き違いを重み付き編集距離で照合します。`Find` は指定した閾値以下の箇所を原文の UTF-8 バイト範囲で返し、`Mask` はその範囲をまとめて置き換えます。

Go 1.22 以降で使えます。外部パッケージへの依存はありません。

```sh
go get github.com/seisuke/yomiyose@v0.1.0
```

```go
package main

import (
	"fmt"
	"log"

	"github.com/seisuke/yomiyose"
)

func main() {
	w := yomiyose.DefaultWeights()
	w.TailLoss = 0.75 // 名前の末尾が1モーラ欠けたとき
	m, err := yomiyose.NewReadings([]string{"イシーカオリ", "アントニオヴィバルディ"}, w)
	if err != nil {
		log.Fatal(err)
	}

	text := "受付のイシイ・カオリさんと、イシイカオさんが来ました。"
	for _, h := range m.Find(text, 1.5) {
		fmt.Printf("%s %q %.2f\n", h.Name, text[h.Start:h.End], h.Cost)
	}
	fmt.Println(m.Mask(text, 1.5, "［氏名］"))
}
```

```text
イシーカオリ "イシイ・カオリ" 0.00
イシーカオリ "イシイカオ" 0.75
受付の［氏名］さんと、［氏名］さんが来ました。
```

`NewReadings` にはカタカナ・ひらがな・ローマ字で名前の読みを渡します。`Match.Name` は登録した読み、`text[h.Start:h.End]` は本文に現れた表記です。同じ人の既知の異表記をひとつの登録名にまとめたい場合は、`New([]Name{{Text: "デビットマッキー", Readings: []string{"デイビットマッキー"}}}, w)` を使えます。

**登録名ごとに規則を指定する**

`New` と `NewReadings` は全規則を使います。日本人名の例から設計した規則と、外国人名の日本語表記から設計した規則を使い分けたいときは、`NewScoped` に姓と名をつないだ読みと規則を渡します。区分は呼び出し側が選びます。名前の由来が不明な場合や、姓と名で両方の規則を使いたい場合は `AllRules`（未指定時の値）を選べます。

```go
m, err := yomiyose.NewScoped([]yomiyose.ScopedName{
	{Name: yomiyose.Name{Text: "サイトウミホ"}, Rules: yomiyose.JapaneseRules},
	{Name: yomiyose.Name{Text: "デビットマッキー"}, Rules: yomiyose.ForeignRules},
	{Name: yomiyose.Name{Text: "オオノデビット"}},
}, yomiyose.DefaultWeights())
if err != nil {
	return err
}
text := "受付にサトウミホさん、デービット・マッキーさんがいます。"
fmt.Println(m.Mask(text, 0.25, "■")) // 受付に■さん、■さんがいます。
```

指定した規則はその登録名の別読みにも適用します。読み2件だけを比較するときは `m.DistanceWithRules(登録読み, 観測した読み, 規則)` で同じ区分を指定できます。`m.Distance` は全規則で計算します。

**照合の重み**

コストが小さいほど近く、閾値と等しい候補も返します。複数の違いを含むときは、適用できる操作の合計コストが最も小さいものを採用します。次の初期値は検索順位を決める仮の値です。

| Weights の項目 | 初期値 | 適用範囲 | 用途 |
|---|---:|---|---|
| LongSpelling | 0 | 共通 | ユウ／ユー、シイ／シーなど、同母音の反復と長音符 |
| EiSpelling | 0 | 共通 | セイ／セー、デイ／デー |
| OuSpelling | 0 | 共通 | トウ／トー |
| LongLoss | 0.25 | 音の並びで区分 | 日本人名はオオノ／オノ、外国人名はデビット／デービットなどの長音の増減 |
| FinalLongLoss | 0.125 | 外国人名 | エディー／エディなど、採用した語末の長音の増減 |
| LongInsertion | 2 | 共通 | 登録読みの短い母音が本文で伸びた場合 |
| LongDeletion | 1.25 | 共通 | 登録読みの長音が本文で短くなった場合 |
| RepeatedVowelPenalty | 2 | 日本人名 | 子音で始まり母音がそろう3モーラ以上の並びで、母音の長さが変わった場合の加点 |
| VowelLoss | 0.25 | 日本人名 | サイトウ／サトウのような、ai の i の有無 |
| GlideAfterOU | +Inf（無効） | 外国人名 | 前後が同じ読みで、直前のモーラの母音がオまたはウのときのア／ワ |
| Geminate | 0.25 | 外国人名 | デビット／デビト、ミッシェル／ミシェルなど、条件付きの促音の有無 |
| BV | 0.25 | 外国人名 | ビ／ヴィを含む、同じ母音を持つバ行とヴの対応 |
| TiChi | 0.25 | 外国人名 | マーティン／マーチンのようなティ／チの交替 |
| KanaSize | 0.25 | 外国人名 | ウィ／ウイ、ウェ／ウエ、シェ／シエを双方向に照合。1組あたりの重み |
| ShiShu | 0.5 | 共通 | シ／シュの交替。タナカシュウジ／タナカシウジ、キム・シウ／キム・シュウはともに0.5 |
| RiRu | 0.5 | 外国人名 | リ／ルの交替。ジェームズ・バリ／ジェームス・パルはズ／ス、バ／パと合わせて1.0 |
| MedialVoicing | 0.25 | 共通、ジェ／シェ・バ／パは外国人名向け | フルネームの先頭以外で清音・濁音が替わる場合。ジェームズ・パジェット／ジェームス・パシェットはズ／スとジェ／シェの2か所で合計0.5 |
| InitialKS | 0.5 | 日本人名 | 語頭のカ行／サ行で母音が対応するもの（カトウ／サトウ） |
| TailLoss | 0.75 | 共通 | 登録名の最後の母音を含む1モーラが本文で欠ける（リョウタ → リョウ） |
| HeadLoss | 1.25 | 共通 | 本文検索で、登録名の先頭1モーラを省いた長い区間を部分マスクする |
| Other | 2 | 共通 | その他の読みの1モーラの挿入・脱落・置換 |
| Hiragana | 0.125 | 共通 | 本文で元がひらがなだった1モーラごとの加点。0にするとカタカナと同点 |

たとえば `m.Distance("サイトウ", "カトウ")` は `0.75` です。語頭の置換が `0.5`、続くイの脱落が `0.25` かかります。`Distance(登録名, 観測した読み)` は読み全体を比較し、本文検索用のひらがな加点を含みません。検索では「イシイカオリ」と「いしいかおり」をそれぞれ `0` と `0.75` で拾います。ある規則を無効にするには対応する重みを `math.Inf(1)` にします。他の規則で説明できる差には、その経路のコストが付きます。

促音は内部で `^`、長音符は `:` として扱います。促音を安く照合する初期条件は、直前が i または u で、その前後のモーラが両側で対応し、後続子音が k・s・t・p・ch・f・h 系の場合です。「エムバペ／エムバッペ」のバとペの間にも適用します。ト／ドやビ／ヴィが同時に替わる場合には、その置換のコストもかかります。「タナカ／タナッカ」には通常コストの `2` がかかります。

「ウィリアムウィリス → ウイリアム・ウイリス」は大小の仮名の違いが2か所あり、距離は `0.5` です。「トマス／トーマス」は「ト」の後に「マス」が続く場合に `LongLoss` を適用します。どちらの規則も、登録読みの途中に現れる姓や名にも使えます。[William Willis の個人名典拠](https://id.ndl.go.jp/auth/ndlna/00461075)・[Theodore Thomas の個人名典拠](https://id.ndl.go.jp/auth/ndlna/00551703)

「レイナ／レーナ」は長さを保つ表記差で、距離は `0` です。「レーナ → レナ」は長音の脱落で `1.25`、逆向きは新しい長音の挿入で `2` です。`LongLoss` の日本人名向けの条件はオ＋ノで、「オオノ → オノ」は `0.25` です。外国人名向けの条件はデ＋ビ／ヴィ、シェ＋ク、ニ＋ナ、ヨ＋ハ、ル＋チの間、マリの直後、ト＋マスの間です。登録読みの末尾がディ、ティ、マリの場合は外国人名向けの `FinalLongLoss` を適用できます。

子音で始まり同じ母音で終わる3モーラ以上の並びでは、一般の長音挿入・脱落コストに `RepeatedVowelPenalty` を加算します。たとえば `tanaka / ta:naka` は通常の編集コスト `Other` も選べるため距離は `2` です。「ヤマモトヨハン」のヨとハの間など、明示的に採用した並びには引き続き `LongLoss` が使えます。この加点は `w.RepeatedVowelPenalty = 0` で外せます。

`ShiShu`、`RiRu` と、外国人名向けの語頭以外のバ／パ・シュ／ジは v0.1.0 の後に追加しました。シュ／ジには `ShiShu + MedialVoicing` を適用します。ジョシュ・ホーキンソン／ジョジホーキンソンの距離は既定値で0.75です。

**短い名前の検索**

`Find` と `Mask` は、すべての規則区分で登録読みと本文の候補の短いほうのモーラ数を使って上限を選びます。姓と名は連結したまま扱います。中黒・空白・アポストロフィは長さに含めません。拗音の「リョ」は1モーラ、長音を含む「リョウ」は2モーラです。

| 短いほうの長さ | 既定の検索条件 |
|---|---|
| 1モーラ | 正規化した読み全体が一致し、ひらがな加点を含むコストが指定閾値以下。`w.ExactSingleMora = false` で通常の距離も許容 |
| 2モーラ | 指定閾値と `w.TwoMoraMaxCost`（初期値 `1.0`）の小さいほう以下。`math.Inf(1)` で指定閾値のみを使用 |
| 3モーラ以上 | 指定閾値以下 |

指定閾値 `1.5` で「サトウレーナ → サトウレナ」は距離 `1.25` でマスクします。「レーナ」だけを渡した場合、同じ本文で比較できる「レナ」は2モーラなので既定では見送ります。`w.TwoMoraMaxCost = 1.25` にするとカタカナの「レナ」まで拾います。「それなら」の「れな」には、さらにひらがな加点が `0.25` かかります。敬称や姓の辞書は不要です。

**範囲とマスク**

フルネームの完全な露出を防ぐため、`Find` と `Mask` は登録読みの先頭1モーラが欠けた長い区間も候補にします。先頭と次のモーラに母音があり、2番目のモーラが本文の開始音と一致し、そこから登録読みに独立した母音を持つモーラが6個以上ある場合が対象です。長音を表す母音、長音符、促音、撥音はこの6個に数えません。登録名「セオドアトーマス」で「スイオドア・トマス」を検索すると、`HeadLoss` と `LongLoss` の合計が `1.5` になり、「スイ■」とマスクできます。読み全体を比較する `Distance` にはこの検索用の割引を適用しません。

- `Find` は原文の順に `Match` を返します。`Start` はUTF-8の開始バイト位置、`End` は終了バイト位置の直後です。`NameIndex` から元の名簿のレコードを取得できます。
- ひらがな・半角カナ・分離した濁点を比較用にそろえ、拗音や「ヴィ」などの組を1モーラと数えます。中黒の「・」「･」は照合から除き、名前の内側にあればマスク範囲に含めます。空白入りの名前は空白を含む表記を登録できます。句読点・改行をまたいで照合しません。
- ローマ字読みには `yuusuke`、`yu:suke`、`yu-suke`、`isii`、`ishii`、`debi^to`、`debitto` などを使えます。原綴りから各国語の発音を自動推定する機能はありません。
- 同じ開始位置・登録読みでは最小コストの区間を選び、同点なら長い方を残します。同じ名前で重なる候補は低コストを優先します。同点で一方が他方を含む場合は長い方を、互いにはみ出す場合は両方を返します。別の登録名の候補は独立に返します。`Mask` は全候補の重なる区間をまとめて置換します。
- 語尾が欠けた候補でも、その直後の長音・促音を挟んで同じ末尾モーラが見えている場合は、その挿入のコストで評価します。「タナッカ」の「タナ」だけを語尾脱落として安く拾うことを防ぎます。
- 短い名前では閾値内に一般語も入り得ます。利用するSTTの文章に対して、マスク漏れと余分に隠した箇所の両方を確認しながら重みを調整してください。

名簿は一度用意すれば、複数の文章・goroutine から共有できます。本文をモーラに分けて出現位置を索引化し、閾値が `Other` より小さいときは語頭で許容する編集を考慮して開始位置を選びます。部分文字列をすべて生成せず、全経路が閾値または発見済みの最良コストを超えたところで比較を終えます。

文章の回帰テストには、姓と名を連結した読みを渡します。対象フルネームの文字がひとつも隠れなければテストが失敗します。一部だけを隠した場合や、似た別人まで隠した場合も実際の出力を記録します。[評価結果と再現手順](EVALUATION.md)

公開STT出力にある「エルドアン／エルドワン」は、変化したア／ワの左右に「ド」と「ン」が共通します。`w.GlideAfterOU = 0.5` にすると、この位置の置換コストを0.5にできます。「ヨシダアヤ」のアの直前はダなので適用しません。モデル・発話ID・元の表記はテストデータから追跡できます。[データの出典と抽出方法](DATA_SOURCES.md)
