# yomiyose

日本語の音声認識（STT）の文字起こしから、あらかじめ読みを登録したフルネームを探してマスクする Go ライブラリです。長音の表記揺れや、聞き取りで名前の一部が欠けた場合も照合できます。

## インストール

Go 1.22 以降で使えます。

```sh
go get github.com/seisuke/yomiyose@v0.1.0
```

## 使用例

2人の読みを登録し、語尾が欠けた「イシイカオ」や、「ジェームズ」が「ジェイムズ」と書かれた箇所を探します。`Find` で登録名・本文中の表記・距離を表示し、`Mask` で一致箇所を置き換えます。

```go
package main

import (
	"fmt"
	"log"

	"github.com/seisuke/yomiyose"
)

func main() {
	m, err := yomiyose.NewReadings([]string{"イシーカオリ", "ジェームズ・スミス"}, yomiyose.DefaultWeights())
	if err != nil {
		log.Fatal(err)
	}
	text := "受付のイシイ・カオリさんと、イシイカオさんが来ました。次はジェイムズ・スミスさんです。"
	for _, h := range m.Find(text, 1.5) {
		fmt.Printf("%s %q %.2f\n", h.Name, text[h.Start:h.End], h.Cost)
	}
	fmt.Println(m.Mask(text, 1.5, "［氏名］"))
}
```

出力

```text
イシーカオリ "イシイ・カオリ" 0.00
イシーカオリ "イシイカオ" 0.75
ジェームズ・スミス "ジェイムズ・スミス" 0.00
受付の［氏名］さんと、［氏名］さんが来ました。次は［氏名］さんです。
```

姓と名をつないだ読みを、カタカナ・ひらがな・ローマ字で登録できます。本文中の位置が必要な場合は `Find` を使い、各一致を `text[h.Start:h.End]` で取り出せます。

## 照合の重み

読みの違いを説明できる操作のうち、合計コストが最小の組み合わせで距離が決まります。`NewReadings` は日本人名向け・外国人名向けの両方の規則を使います。

| 適用範囲 | `Weights` の項目（抜粋） | 適用する操作 | 既定コスト |
|---|---|---|---:|
| 共通 | `LongSpelling` | 同じ母音の反復と長音符を読み替える（シー ↔ シイ） | 0 |
| 共通 | `EiSpelling` | エ段の長音と「イ」を読み替える（ジェー ↔ ジェイ） | 0 |
| 共通 | `TailLoss` | 登録名の末尾で母音を含む1モーラが欠ける（カオリ → カオ） | 0.75 |
| 共通 | `Other` | 通常の1モーラの挿入・脱落・置換 | 2 |
| 日本人名向け | `VowelLoss` | 母音が a のモーラに続くイの有無（サイトウ ↔ サトウ） | 0.25 |
| 日本人名向け | `KuGemination`（開発版） | カ行音の前で「ク」が「ッ」になる（キクコ → キッコ） | 0.5 |
| 日本人名向け | `InitialKS` | 語頭のカ行とサ行を、母音を保って置き換える（カトウ ↔ サトウ） | 0.5 |
| 外国人名向け | `BV` | 同じ母音をもつバ行とヴの音を置き換える（ビ ↔ ヴィ） | 0.25 |
| 外国人名向け | `Geminate` | 前後の音に応じた促音「ッ」の有無（デビット ↔ デビト） | 0.25 |

使用例の「イシーカオリ → イシイカオ」では、「シー → シイ」が `0`、末尾の「リ」の脱落が `0.75` です。合計 `0.75` は指定した閾値 `1.5` 以下なのでマスクされます。

規則ごとのコストは `DefaultWeights()` の各項目で調整できます。[重みの一覧と照合規則](docs/matching/README.md)
