# yomiyose

日本人名・外国人名の読みを文字起こしの中から探し、元の文章でマスクできる範囲を返す Go ライブラリです。Go 1.22 以降、外部依存はありません。

```go
package main

import (
	"fmt"
	"log"

	"github.com/seisuke/yomiyose"
)

func main() {
	w := yomiyose.DefaultWeights()
	w.TailLoss = 0.75 // 名前の末尾が1モーラ欠けたとき
	m, err := yomiyose.NewReadings([]string{"イシーカオリ", "ヴィバルディ"}, w)
	if err != nil {
		log.Fatal(err)
	}

	text := "受付のイシイ・カオリさんと、イシイカオさんが来ました。"
	for _, h := range m.Find(text, 1.5) {
		fmt.Printf("%s %q %.2f\n", h.Name, text[h.Start:h.End], h.Cost)
	}
	fmt.Println(m.Mask(text, 1.5, "［氏名］"))
}
```

```text
イシーカオリ "イシイ・カオリ" 0.00
イシーカオリ "イシイカオ" 0.75
受付の［氏名］さんと、［氏名］さんが来ました。
```

`NewReadings` にはカタカナ・ひらがな・ローマ字で名前の読みを渡します。`Match.Name` は登録した読み、`text[h.Start:h.End]` は本文に現れた表記です。同じ人の既知の異表記をひとつの登録名にまとめたい場合は、`New([]Name{{Text: "デビット", Readings: []string{"デイビット"}}}, w)` を使えます。

**照合の重み**

コストが小さいほど近く、閾値と等しい候補も返します。複数の違いを含むときは、適用できる操作の合計コストが最も小さいものを採用します。次の初期値は検索順位を決める仮の値です。

| Weights の項目 | 初期値 | 用途 |
|---|---:|---|
| LongSpelling | 0 | ユウ／ユー、シイ／シーなど、同母音の反復と長音符 |
| EiSpelling | 0 | セイ／セー、デイ／デー |
| OuSpelling | 0 | トウ／トー |
| LongLoss | 0.25 | デー／デのような、同じ母音に続く長さの違い |
| FinalLongLoss | 0.125 | エディー／エディのような語末の長さの違い |
| VowelLoss | 0.25 | サイトウ／サトウのような、ai の i の有無 |
| Geminate | 0.25 | デビット／デビト、ミッシェル／ミシェルなど、条件付きの促音の有無 |
| BV | 0.25 | ビ／ヴィを含む、同じ母音を持つバ行とヴの対応 |
| TiChi | 0.25 | マーティン／マーチンのようなティ／チの交替 |
| MedialVoicing | 0.25 | 語頭以外での清音・濁音の対応（デビット／デビッド、ジョセフ／ジョゼフなど） |
| InitialKS | 0.5 | 語頭のカ行／サ行で母音が対応するもの（カトウ／サトウ） |
| TailLoss | 0.75 | 登録名の最後の母音を含む1モーラが本文で欠ける（リョウタ → リョウ） |
| Other | 2 | その他の読みの1モーラの挿入・脱落・置換 |
| Hiragana | 0.125 | 本文で元がひらがなだった1モーラごとの加点。0にするとカタカナと同点 |

たとえば `m.Distance("サイトウ", "カトウ")` は `0.75` です。語頭の置換が `0.5`、続くイの脱落が `0.25` かかります。`Distance(登録名, 観測した読み)` は読み全体を比較し、本文検索用のひらがな加点を含みません。検索では「イシイカオリ」と「いしいかおり」をそれぞれ `0` と `0.75` で拾います。ある規則を無効にするには対応する重みを `math.Inf(1)` にします。他の規則で説明できる差には、その経路のコストが付きます。

促音は内部で `^`、長音符は `:` として扱います。促音を安く照合する初期条件は、直前が i または u で、その前後のモーラが両側で対応し、後続子音が k・s・t・p・ch・f・h 系の場合です。ト／ドやビ／ヴィが同時に替わる場合には、その置換のコストもかかります。たとえば「タナカ／タナッカ」には通常コストの `2` がかかります。この文脈条件は本ライブラリの初期設定です。

**範囲とマスク**

- `Find` は原文の順に `Match` を返します。`Start` はUTF-8の開始バイト位置、`End` は終了バイト位置の直後です。`NameIndex` から元の名簿のレコードを取得できます。
- ひらがな・半角カナ・分離した濁点を比較用にそろえ、拗音や「ヴィ」などの組を1モーラと数えます。中黒の「・」「･」は照合から除き、名前の内側にあればマスク範囲に含めます。空白入りの名前は空白を含む表記を登録できます。句読点・改行をまたいで照合しません。
- ローマ字読みには `yuusuke`、`yu:suke`、`yu-suke`、`isii`、`ishii`、`debi^to`、`debitto` などを使えます。原綴りから各国語の発音を自動推定する機能はありません。
- 同じ開始位置・登録読みでは最小コストの区間を選び、同点なら長い方を残します。同じ名前で重なる候補は低コストを優先します。同点で一方が他方を含む場合は長い方を、互いにはみ出す場合は両方を返します。別の登録名の候補は独立に返します。`Mask` は全候補の重なる区間をまとめて置換します。
- 短い名前では閾値内に一般語も入り得ます。利用するSTTの文章に対して、マスク漏れと余分に隠した箇所の両方を確認しながら重みを調整してください。

名簿は一度用意すれば、複数の文章・goroutine から共有できます。本文をモーラに分けて出現位置を索引化し、閾値が `Other` より小さいときは語頭が一致するか、許容する語頭の置換が可能な位置から比較します。部分文字列をすべて生成せず、全経路が閾値または発見済みの最良コストを超えたところで比較を終えます。
